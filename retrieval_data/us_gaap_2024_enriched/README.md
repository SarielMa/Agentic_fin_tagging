```bash
python data_whole_pipeline/build_us_gaap_2024_retrieval_dataset.py
```

Output:

- `us_gaap_2024_enriched_retrieval.jsonl`: one US-GAAP concept per line.
- `summary.json`: source paths and coverage counts.
- `sample.json`: formatted sample for `OperatingLeaseCost`.

Schema:

- `tag`: US-GAAP concept name without the `us-gaap:` prefix.
- `type`: XBRL item type, such as `monetaryItemType`.
- `standard_label`: readable standard label.
- `documentation`: documentation label from `us-gaap-doc-2024.xml`.
- `references`: paragraph-level ASC references from `us-gaap-ref-2024.xml`.
- `retrieval_text`: `tag`, `standard_label`, and `documentation` joined for retrieval.
